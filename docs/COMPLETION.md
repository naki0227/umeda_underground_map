## 3. 地図データの出典とライセンスの方針

- **他サイトの画像・地図タイル・ロゴはリポジトリに入れない。** 地図はアプリ内の SVG 描画のみで、外部タイルは使わない
- 公式サイト（各地下街のフロアガイド等）からは **店名などの事実情報のみ** を参照し、フロアマップ画像やロゴは使わない
- 出口番号・緯度経度・通路形状・地下店舗の位置は **OpenStreetMap（© OpenStreetMap contributors、ODbL 1.0）** から取り込む想定。ODbL の条件（帰属表示、派生データベースを ODbL で提供）を守る（→ 確かめてほしいこと 1）
- ライセンス上使えないデータ（利用規約で再配布不可のもの、出典不明のもの）は使わない。既存データのうち出典が記録されていない座標は C-2 で公開データ由来の値に置き換える

## 5. 確かめてほしいこと

1. **OpenStreetMap データの採用**: 出口・通路・地下店舗を網羅するには OSM（ODbL）を使うのが、ライセンス上安全に取れる唯一の公開データと判断した。採用すると `src/data/` 以下の派生データベースは ODbL で公開することになり、アプリと README に「© OpenStreetMap contributors」の表示が必要になる。採用してよいか（不可なら C-1/C-2/C-4/C-5 は手入力データの範囲に縮小する）
2. **中国語・韓国語**: UI 文言は機械的な翻訳になる。ネイティブ確認をするか。地名・店名は英語表記のフォールバックでよいか
3. **コードのライセンス**: リポジトリに LICENSE がない。コードに付けるライセンス（例: MIT）を決めてほしい。決まるまでは README に「コードのライセンスは未設定」と書く
4. **既存の店舗データ**: 公式サイト掲載の店名（事実情報）を手入力したもの。OSM 由来データと重複する場合は OSM 側に寄せてよいか（出典を一本化できる）
5. **地上ルート提案のしきい値**: 「地下経路が地上直線距離の 1.6 倍を超えたら地上を提案」でよいか
