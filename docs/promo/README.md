# 宣伝用の素材

| ファイル  | 中身                                                                                        |
| --------- | ------------------------------------------------------------------------------------------- |
| `bgm.m4a` | YouTube の英語の宣伝動画の BGM。40 秒。サンプルを使わず一から合成したので、権利の問題はない |

BGM は enludus-daily/yt-pipeline の `common/bgm.py`（プリセット `umeda`：102 BPM・ペンタトニック・エレピ・足音のリズム）で作った。アプリでは使っていない（`public/` の外に置いているので、サイトにも出ない）。
