# 地図の文字を減らしてアイコンに

- 日時: 2026-10-24
- ブランチ: claude/map-icons（claude/fpv-scene の上）

## 依頼

ふだんの地図の文字が多すぎる。分かりやすいアイコン表示などで工夫してほしい。

## やったこと

- 地上の建物: 灰色の四角をやめ、種類のアイコンの丸（🏬 百貨店、🛍️ 商業施設、🏢 ビル、🚌 バスターミナル、🚉 駅、⛩️ 神社、📮 郵便局、🎡 HEP FIVE、🌳 グラングリーン など）。名前は拡大したとき（詳細表示）と選んだときだけ。
- 改札: 🚉 のアイコンに、路線の色の札で短い路線名（JR・阪急・阪神・御堂筋線・谷町線・四つ橋線）。拡大するとフルの名前。
- 広場: ⛲ のアイコンと名前。ビルの地下（大阪駅前第1〜4ビル B1）はアイコンだけ（拡大で名前）。
- 番号を出さない出口の点を小さく、白抜きに。
- 新しい `src/features/map/mapIcons.ts` にアイコン・路線の対応をまとめた。

## テスト

- mapIcons（建物のアイコン・改札の路線と色・短い名前）、mapLabels（ふだんは建物名なし、拡大で全部）
- typecheck / format / lint / test（202件）/ build 通過。390×844 のスクリーンショットで確認
