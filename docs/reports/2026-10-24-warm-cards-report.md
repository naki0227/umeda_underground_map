# シート・カードを「温かい飲食」の型に（lp-anatomy の学び）

- 日時: 2026-10-24
- ブランチ: claude/warm-cards（claude/type-scale の上）

## 元になった学び

lp-anatomy の解剖ノート（2026-10-17・びっくりドンキー）の実際の値を使った。

- 背景は白にせず、紙色2色（#efebea / #e7dacb）。白はカードとヘッダーだけ
- 文字は焦げ茶の3段（#3b201b 本文・#60352c ボタンの文字・#937872 番号やラベル）
- カードに枠線を引かず、締まった茶の影 `1px 1px 2px rgba(73,35,29,.25)` で浮かせる。罫線は `rgba(96,53,44,.18)` の区切りだけ
- 角丸は上を大きく（28 / 28 / 14 / 14px）
- 数字・日付・ラベルは丸い字
- ホバーは「揺れ」（0.75秒・±3°）

## 1回目からの見直し（ユーザーの指摘：色味と枠線を応用、AI っぽさをなくす）

1回目は紙色と角丸・アーチを足しただけで、次のような「よくある見た目」が残っていた。

- 左の色帯（inset の縦線）でいまの手順・注意を示す
- ぼかしの大きい影、1px の枠線、輪郭線の丸いチップ
- 次の動きのカードが青一色の塊

2回目でこれらをやめ、ノートの型にそろえた。

## やったこと

- 色のトークン: `--paper`（#efebea）・`--bg-soft`（#e7dacb クラフト）・`--bg`（白、カードとヘッダーだけ）、文字 `--text-strong` / `--text` / `--text-sub`、罫線 `--border`、影 `--shadow-card`（カード）・`--shadow-float`（地図の上に浮かぶもの）、角丸 `--radius-card`（28/28/14/14）・`--radius-s`（14）、丸い字 `--font-round`（端末の丸ゴシック。Webフォントは読まない）、押す所の色 `--action`（経路の青）。
- 枠線をなくした所: 検索欄・現在地欄・検索結果・拡大縮小・階の切り替え・シート・おすすめスポット・候補・お気に入り・凡例・GPS のお知らせ。かわりに締まった茶の影。入力欄とチップはクラフト紙色の面。
- シートは紙色、中のカードは白（地図上部の欄も白いヘッダー）。
- 次の動きのカード: 白いカード（角丸 28/28/14/14）に、青い丸の中の矢印。距離は丸い字で灰茶。一人称の画面の上のカードも同じ形に。
- 手順の一覧: 枠や帯をやめ、点線の罫で区切る。いまの手順だけ白いカード。距離は丸い字。
- ボタン: 主は経路の青、副はクラフト紙色に焦げ茶の文字。オンのチップは焦げ茶で塗る。
- 本文の行間 1.7・字間 .02em（ノートの本文 1.76・.025〜.05em に寄せる）。
- おすすめスポットのカードはマウスで一度揺れる（マウス端末だけ。reduced-motion・データセーバーでは揺れない）。
