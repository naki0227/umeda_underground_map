# 作業報告書: 遠回りの経路を点検し、通路のつながりを直す

## 作業日時

2026年10月20日 17時46分56秒

## 作業目的

「直線では近いのに経路がとても長い」組が多く、地図の通路の抜けが疑われたため、通路グラフを点検して直す。

## 点検の方法

アプリのグラフ（全ノードの組）について、直線距離が 120m 以内で、経路が直線の 3 倍以上かつ 150m 以上長い組を数え、集中している場所を OSM の元データと重ねた図で調べた。

## 見つかったことと直したこと

1. **出口が別の出口につながっていた（不具合）**: 出口を通路につなぐとき、先につないだ別の出口もつなぎ先の候補になっていた（例: D-44 → D-40、10-8 → E-15）。このため「地上へ出て隣の出口から下りる」道が経路に入っていた
   - `scripts/osm/network.mjs`: 出口のつなぎ先を通路の点だけにした
   - `scripts/osm/build.mjs`: 2 つ以上の出口につながる点を縮約で消さない（消すと出口どうしが直接つながる）
   - `src/domain/route.ts`: 出口は出発点・到着点のときだけ使い、途中では通らない
2. **出口でしかつながっていない小さなかたまり**（JR大阪駅 桜橋口の 1F 部分、C-80・F-85・H-43 付近の階段の踊り場など）: 20m 以内の主な通路網の点とつないだ（6 か所）。桜橋口 ↔ C-1 出口付近は 6m なのに経路が 218m だったのが直った
3. **地下街の中の行き止まり**: ディアモールの D-40 付近の階段の下端が、20m 先の通路とつながっていなかった（経路 217m）。地下街ポリゴンの中の行き止まりは、同じ地下街の 25m 以内の点とつなぐ（大回りのときだけ。1 か所）
4. **大阪駅前ビルの B1**: 建物の中心から通路へ 1 本だけつないでいたため、ビルの横の出口へも大回りになっていた（例: 第4ビル B1 → 10-22 出口が直線 36m で経路 590m）。第1・第2・第4ビルは建物の外形の中か 15m 以内の B1 の通路の点すべてとつないだ（27 本）
