## 点検のしかた

3つの観点で並べて点検し、見つかったものは手元で確かめてから直した。

- コードの不具合: 主な画面・地図の操作・経路・お気に入り・現在地・音声を読み、データ（444 ノード・400 経路）と i18n のキーを機械的に確認
- 見やすさ・操作: iPhone 13・360×640・横向き・PC 幅で ja/en/zh/ko の主な流れを撮影し、axe とコントラストの計算、キーボードの Tab 順
- 重さ・PWA・検索: CPU 4 倍遅い端末のエミュレーションで地図の操作を計測、バンドル、マニフェスト、Service Worker、robots / sitemap / canonical

## 直したこと

### 不具合

- 案内中に地図タブを押すと一人称に戻る → 地図だけを出す
- ホイールでページごと拡大される・横スクロールで拡大される・ピンチが指の間を中心にしない・画面を回したあとパンの速さがずれる
- 「階段とエスカレーター」が並ぶ通路で、一人称の札は「階段」、案内文は「エスカレーター」になる → 同じ選び方に。「階段を避ける」でもこの通路は避けない
- 一人称⇄地図の切り替えでシートの高さが変わらない、出発地と目的地が同じときに「到着まで約1分・0m」
- 現在地の推定が、入口や店を変えても古い結果のまま。GPS が失敗しても前の位置が残る
- 案内中に通路が閉まる時刻をまたいでも経路が変わらない → 1分ごとに時刻を進める（同じ経路ならステップはそのまま）
- 地図データを作り直すとお気に入りのノードが消える・別の場所になる → 読み込み時に同じ名前の場所へ付け替え、駅は改札を引き直す

### 重さ

- 拡大した地図のドラッグが重い（文字 400 個ほどを動かすたびに配置し直していた）。動かしている間は地図を包む要素を CSS で動かし、指を離したとき（ホイールは止まってから）1回だけ描き直すようにした
  - 拡大した状態で 40 回動かす: 約 20.6 秒 → 約 2.0 秒（長いタスクの合計 18.3 秒 → 1.1 秒）
  - 動かし終わった位置は以前と同じ（スクリーンショットで確認）。ピンチは指の間の地点が動かないことを確認
- 店名の段の計算（二重ループ）を1回に、日本時間の時計を使い回す

### 見やすさ・操作

- コントラスト 4.5:1 未満だった文字（番号・距離のグレー、水色・オレンジの文字、白文字の「迷った」・階の切り替え・出口の札）を濃くした。トークンを確かめるテストを追加
- 閉じる×（26px → 44px）・シートのつまみ・前へ/次へ・お気に入りのボタンを押しやすく
- シートが低いとき「ここへ行く」「前へ/次へ」が隠れる → シートの下端に残す。横向きでシートが潰れる → 最小 160px
- シートを Esc で閉じる、開いたらシートへフォーカス、閉じたら元へ。キーボードで現在地・検索に先に届く
- iPhone の切り欠きの余白、韓国語の案内の札がはみ出す
- 英語の案内「Turn left at Near Exit C-7」→「Turn left at Exit C-7」、日本語「『C-7出口付近』を左へ」→「…で左へ」、用語の揺れ（再測位・ドーチカ）、韓国語・中国語の細かな直し

### 検索・共有・インストール

- robots.txt・sitemap.xml（公開URLをビルド時に書き込む）、canonical、構造化データ（WebApplication）
- 404.html（GitHub Pages で知らない URL を開いてもアプリを出す）
- ホーム画面の名前を「梅田地下ナビ」に、theme-color を画面の紙色に
- ホーム画面から開いたまま裏に回ったアプリも、戻ってきたときに新しい版を確かめる（再読み込みはしない）
