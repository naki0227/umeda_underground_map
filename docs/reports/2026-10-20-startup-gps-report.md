## 変更内容

- `src/domain/geo.ts`（新規）: 緯度経度と平面座標を両方持つノード（出口・改札）から最小二乗でアフィン変換を求める `fitGeoToMap`、最寄りノード `nearestNode`
- `useInitialGeolocation`: 起動時に1回だけ `getCurrentPosition`。Permissions API で拒否済みなら何もしない。`watchPosition` は使わない
- 地図: 誤差円（地面の円を等角投影した楕円、20〜300m に制限）と中心点「おおよその現在地（GPS）」。取得できたらそこへ寄せる。タップで位置確定シートを開き、GPS 位置を推定ヒントとして渡す
- ◎ ボタン（ズームボタンの列）で再取得。取得中は無効化
- 最寄りノードから 600m 超なら円は描かず「地図の範囲外にいるようです」を表示（タップで閉じる）
- 失敗・拒否時は何も表示しない（従来どおり）
