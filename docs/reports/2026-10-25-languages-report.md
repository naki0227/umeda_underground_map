# 多言語対応の拡大（韓国語・中国語を筆頭に）

- 日時: 2026-10-25
- ブランチ: claude/more-languages（claude/en-names の上）

## やったこと

### 地名・店名の韓国語・中国語

これまで韓国語・中国語の画面でも、地名・店名は英語だった。`src/data/placeNames.ts` で、地図データを組み立てるときに簡体字・繁体字・韓国語の名前を足す。

- 表（約 70 件）: 改札（「JR 오사카역 미도스지 출구」「JR大阪站 御堂筋口」）・広場・地下街の区画・地上スポット・ビル
- 形から組み立てる: 「C-7出口付近」→「C-7出口附近」「C-7 출구 부근」、「◯◯前」→「◯◯前」「◯◯ 앞」、「◯◯の通路」「◯◯ B1」など。英語名も同じ形のときだけ（店名がたまたま「…前」で終わる場合は組み立てない）
- チェーン店（約 30）: 各社の中国語・韓国語の表記（星巴克・全家・罗森 / 스타벅스・패밀리마트・로손 など）。支店名つき（「タリーズコーヒー ディアモール大阪店」）もチェーン名で
- ほかの店: 中国語は、かなを含まない（漢字だけの）店名なら日本語のまま（中国語の読み手にも読める）、それ以外は英語名。韓国語は英語名
- 駅（駅として検索する 7 駅）にも名前と言い方（「오사카역」「梅田站」など）を足した。検索は韓国語・中国語の名前でも見つかる（「스타벅스」「星巴克」）

### 画面の言語を 4 → 10

繁體中文・ไทย・Tiếng Việt・Bahasa Indonesia・Français・Español を追加。端末の言語で自動で選ぶ（台湾・香港は繁體中文。これまでは英語だった）。読み上げも各言語の声で。

- すべての言語で、画面の文言のキーと `{{…}}` の差し込みが日本語と同じことをテストで確認
- 地名・店名は、タイ語・ベトナム語・インドネシア語・フランス語・スペイン語では英語名

## 確認

- 韓国語・繁體中文・タイ語で、現在地の設定 → 検索（「스타벅스」「星巴克」）→ 道案内（「"D-13 출구 부근"에서 오른쪽으로」「在「D-13出口附近」右轉」）→ 一人称を Playwright で確認
- test 263 件・typecheck・lint・format・build 通過

## 残ること

- 韓国語の店名（チェーン以外）は英語名。主な店から表に足すとよい
- 翻訳はネイティブの確認を受けていない。おかしな言い回しは報告フォームで集める
