# 作業報告書: 地下でつながる通路網すべてを取り込む

## 作業日時

2026年10月20日 18時52分38秒

## 作業目的

地図を「つながっている所全部」に広げる。これまでは四角い範囲（約 1km × 1.2km）で切っていた。

## 調べたこと

- 約 2.7km × 3.1km（北: 中津寄り、南: 中之島、東: 扇町寄り、西: 福島寄り）を OSM API から取得し、地下の歩行網を作って連結成分を調べた
- JR大阪駅とつながる通路網は 390 点。そのうち旧範囲の外は西梅田側（ガーデンアベニュー、6-1 出口まで）だけだった
- それ以外の地下の通路（堺筋線、中之島、梅田センタービルなど）は梅田の通路網と 230m 以上離れていて、OSM ではつながっていない。グランフロント大阪・うめきたの地下や、東梅田より東の通路は OSM に地下の通路として描かれていない

## 変更内容

- `scripts/osm/fetch.mjs`（新規）: OSM API の map 呼び出しを約 500m 四方ずつ 36 回行い、1 つの OSM XML にまとめる（依存なし）
- `scripts/osm/overlay.mjs`: `REGION` を取得範囲いっぱいにした。残るのは JR大阪駅 御堂筋口とつながる通路網だけなので、OSM に通路が描き足されれば作り直すだけで地図が広がる
- データを作り直した: 出口 148 → 161（西梅田側 6-1〜6-36・A-3・A-11 の 12 出口）、ノード 418 → 444、店 357 → 362
- `InteractiveMap.test.tsx`: 地図が大きくなり、拡大を 6 回繰り返すテストが CI の 5 秒の制限に近づいたため、App のテストと同じく 15 秒にした
- README・`docs/COMPLETION.md`・`scripts/osm/README.md` の手順と数値を更新
