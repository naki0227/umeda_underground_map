# 作業報告書: 地図を見やすく・使いやすく

## 作業日時

2026年10月20日 02時57分00秒

## 作業目的

オーナーの依頼「もっと地図を見やすく使いやすくしてほしい」。データが増えた（出口 148・店 357）ことで、地図が見づらくなっていた。

## 見つけた問題（改善前のスクリーンショットで確認）

1. 全体表示で出口バッジ 148 個・建物 32 個・点線・店の点が重なり、地下の通路が見えない
2. 建物の箱がマップ単位の大きさで、拡大すると画面を覆う
3. 検索などで場所を選んでも、地図がその場所へ動かない
4. 案内開始時に最初の区間しか映らず、経路の線も通路と似た色で目立たない

## 変更内容

- **拡大率に応じた表示の出し分け**（`detail.ts`）: 全体表示（k≥1.6）では店の点・設備チップ・分岐の点を出さず、出口は点だけにする。通常（0.7≤k<1.6）では出口番号・店の点・設備を出す。詳細（k<0.7）では店名も出す。いずれもラベルの重なり判定の中で出す
- **建物を一定サイズの小さな立体アイコンに**（`ground.ts` / `MapGroundLayer.tsx`）: 地上スポット自身の位置に描く。出口への点線は選択中・目的地のものだけ表示。見た目より広い当たり判定
- **場所を選ぶと地図が寄る**: 引いた表示なら拡大して寄せ、選んだ場所にリング（点滅、モーション低減設定では静止）を表示
- **経路の表示**:
  - 経路が出たら経路全体、ステップを送ったらその区間が、上の検索バーと下のシートに隠れない範囲に収まるよう拡大率と位置を合わせる（`fitRectViewBox`）
  - 経路は白縁＋濃い青、いまの区間はオレンジで表示し、70px ごとに進行方向の矢印を置く（`routeArrows.ts`）。線の太さは拡大しても画面上で一定
  - 経路以外の通路・店・出口・建物を薄くする。経路上の出口は青
  - 「経路全体を表示」ボタン（⤢）と凡例「経路」を追加
- 小さな出口の点にも透明な当たり判定を付け、指で押しやすくした
- README のスクリーンショットを新しい表示に差し替え
