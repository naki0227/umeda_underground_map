# 作業報告書: 経路の青と選択の黄を CSS 変数にまとめる

## 作業日時

2026年10月20日 12時33分28秒

## 作業目的

LP の品質基準（lp-anatomy の APPLY.md「色・フォントをトークン（CSS 変数）にまとめる」）を当てはめる。経路の青と選択の黄が `src/index.css` に直書きされていたので、変数にして 1 か所で変えられるようにする。

## 変更内容

- `:root` に `--route`（経路の青 `#1d4ed8`）、`--select`（選択の黄 `#f59e0b`）、`--select-soft`（`#fde68a`）、`--select-ring`（`rgba(245, 158, 11, 0.15)`）を追加
- 置き換えた箇所
  - `--route`: 経路の線、経路上の出口バッジ、凡例の経路
  - `--select` 系: 選んだ場所の目印（輪）、選んだ建物の上面、いまのステップの強調線、地図上のフォーカス枠
- 色の値は変えていない。GPS の大まかな位置の青と、お気に入りの星の黄は意味が違うので対象外

## 確かめたこと

- 変更前後のビルドで、場所を選んだ画面・道案内の画面・経路を表示した地図のスクリーンショット（390×844）を撮り、3 枚ともピクセル単位で一致（ファイルのハッシュが同じ）
