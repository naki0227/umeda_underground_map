## 見つけた不具合と対応

| #   | 不具合                                                                                                        | 対応                                                                                                                  |
| --- | ------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------- |
| 1   | 地図のピンをタップすると別の場所が開く（建物ラベル・階段リンクが上に重なってタップを奪う。約 110 個中 43 個） | ラベル・リンク・マーカーを `pointer-events: none` に。再計測で残りは固定 UI（ズームボタン）の下と建物本体の重なりのみ |
| 2   | 入口セレクトで同じ出口を指すスポット（大丸とルクア等）を選ぶと別の名前が表示される                            | 選択肢の値を `poi:ID` / `node:ID` で一意化                                                                            |
| 3   | 「階段を避ける」を押しても経路が変わらず、何も表示されない（階段エッジはすべて出口への一本道）                | 経路に階段が残るときは警告を表示（`routeUsesStairs`）。`aria-pressed` 追加。JR 御堂筋口 ↔ J-1 を階段属性に            |
| 4   | お初天神・阪神百貨店・大阪駅前ビルが出口のない分岐ノードに対応していた                                        | 出口・改札に付け替え、「スポットは出口か改札を指す」データテストを追加                                                |
| 5   | 英語に切り替えても `<html lang="ja">` のまま。再読み込みで言語が戻る                                          | `languageChanged` で `lang` 更新、localStorage に保存（使えない環境では無視）                                         |
| 6   | 地図のピンをキーボードで操作できない                                                                          | ピン・出口バッジ・店ピン・建物を `role="button"` + `tabIndex` + Enter/Space 対応に                                    |
| 7   | 案内中に経路シートを閉じられず地図が見えない                                                                  | 経路シートに閉じるボタン、閉じた後は「道案内を表示する」バナーで再表示                                                |
| 8   | 到着ステップが目的地の店名ではなくノード名                                                                    | 最終到着は目的地名で表示（地上スポットは出口名のまま）                                                                |
| 9   | 「迷った」の説明文が表示されない                                                                              | 迷った後の位置確定シートに説明を表示                                                                                  |
| 10  | 状態更新関数の中で別の setState を呼んでいた                                                                  | クロージャから読む純粋な更新に変更                                                                                    |
| 11  | 検索で通路名（「ekimo梅田 北」など）・出口番号が見つからない、Escape で閉じない                               | 検索対象に追加、Escape でクリア                                                                                       |
| 12  | 位置情報ボタンに取得中表示がない、推定カードが画面外に出る                                                    | 取得中表示と無効化、推定カードを表示位置へスクロール                                                                  |
| 13  | 未使用の翻訳キー、メニューの見出しが h1、タブに現在位置がない                                                 | 削除、h2 に、`aria-current`                                                                                           |
