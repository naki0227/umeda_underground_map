# 文字の大きさを6段に、文を短く（lp-anatomy の学び）

- 日時: 2026-10-24
- ブランチ: claude/type-scale

## 元になった学び（lp-anatomy）

- 横断ルール2「文字は極端な対比。中途半端なサイズを並べない」
- とらや「大きさは6段（12 / 14 / 16 / 20 / 24 / 32px）」、ほぼ日「見出しは2段、段は rem で決める」
- APPLY「色・フォントをトークン（CSS 変数）にまとめる」、ルール8「文字に下限をつける」

## 変更前

`index.css` の文字の大きさが 21 種類（0.7 / 0.75 / 0.8 / 0.85 / 0.9 / 0.95 / 1 / 1.02 / 1.05 / 1.1 / 1.15 / 1.2 / 1.4 / 1.6 / 1.8 / 2.2rem と 11 / 12 / 13 / 14 / 16px）。見出し（1.05rem ≒ 17px）と本文（0.95rem ≒ 15px）の差が小さく、11px の小さな文字もあった。

## やったこと

- `:root` に `--fs-xs`（12）〜 `--fs-2xl`（32）の6段を置き、全 48 か所をこの段に置き換えた。
  - 12: 補足・ラベル・地図の文字（下限。11px はなくした）
  - 14: 説明・注意・チップ
  - 16: 本文・ボタン・入力（16px 未満だと iPhone で入力時に画面が拡大される）
  - 20: シートの見出し・アイコン
  - 24: 閉じる・拡大縮小
  - 32: 案内の距離・次の動きのアイコン
- 地図のラベル（SVG）の大きさも段に合わせた（設備 11→12、沿道の店名 13→14）。
- 長い文を短くした（4言語）: 推定位置の注意、階段の注意、地上の目的地の案内、お気に入りが空のとき、おすすめスポットの説明。

## テスト

- `typeScale.test.ts`: 段が6つで 12px 以上、すべての font-size が段の変数、入力欄は 16px、地図のラベルも段の大きさ
- typecheck / format / lint / test（206件）/ build 通過。変更前後のスクリーンショット（場所・道案内・おすすめスポットのシート）で確認
