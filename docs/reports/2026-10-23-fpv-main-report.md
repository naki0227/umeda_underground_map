# 案内中は一人称を主役に（左上に小さな地図）

- 日時: 2026-10-23
- ブランチ: claude/fpv-main（claude/label-hierarchy の上）

## やったこと

- 案内中の一人称の表示を、画面の上端から下のシート（peek）の上までを使う主役の表示にした。
  通路の絵は余った高さに合わせて大きくなる。
- 左上に小さな地図（132px）を追加。いまの区間の起点を中心に、進む向きが上になるよう回して、
  まわりの通路・経路（薄い青）・いまの区間（濃い青）・目的地・現在地の矢印を描く。押すと全体の地図に切り替わる。
- 小さな地図の右に「1 / 4」のステップ番号と、次の動き（アイコン＋「約230m先で右へ」）を大きく出す。
- 一人称のときは道案内シートを peek（画面の 30%）で開き、一人称の表示を隠さない。

## 変えたファイル

- `src/features/route/miniMapGeometry.ts`（新規）: 進む向きを上にする座標変換
- `src/features/route/MiniMap.tsx`（新規）: 小さな地図
- `src/features/route/FirstPersonView.tsx`: 小さな地図とステップ番号の枠
- `src/App.tsx`: 小さな地図の組み込み、一人称のときシートを peek に
- `src/index.css`: 一人称の表示のレイアウト、小さな地図の色
- `src/i18n/locales/*.ts`: `fpv.openMap`

## テスト

- miniMapGeometry: 進む向きが上・中心・縮尺
- MiniMap: 通路・経路・区間を描く、区間の起点が中心、押すと地図を開く、起点がないときは描かない
- FirstPersonView: ステップ番号と小さな地図の枠
- App: 案内開始時に小さな地図とステップ番号が出て、押すと一人称が閉じる
- typecheck / format / lint / test（181件）/ build すべて通過。390×844 のスクリーンショットで確認
