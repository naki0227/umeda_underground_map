# 一人称を画面いっぱいの「通路の絵」に

- 日時: 2026-10-24
- ブランチ: claude/fpv-scene

## 依頼

- 地図の色が無機質
- 一人称は地図の上のポップアップではなく、画面ごと切り替える。左上に小さな地図（元の地図の上の経路、Google マップのように）
- 左右の店を文字の一覧で並べず、一人称の絵の中に（アイコンでよい）
- まっすぐの通路だけでなく曲がり角も描き、店ごとに四角で分ける

## やったこと

- 一人称の画面: 案内を始めると地図・検索欄を隠し、画面いっぱいに通路の絵を出す。下には操作だけの道案内シート（前へ・次へ・階段を避ける・音声案内）。
- 通路の絵（`src/features/route/scene/`）:
  - いまの区間の起点から経路に沿って 100m 先までを、床・壁・天井を 4m ごとに区切った多角形にして透視投影で描く（遠いものから順に描く）。曲がり角の先の通路も見える。
  - 床に経路の青い帯、曲がる所に大きな矢印。
  - 壁には店ごとに 5m の店先（下はガラス、上は種類の色の看板）。出口は黄色の看板と階段の口、脇道は開口。
  - 店名・出口番号は吹き出し（アイコン + 名前、遠い店はアイコンだけ）。重なるものは近い方を優先し、角の向こうに隠れるものは出さない。
  - 左右の一覧は画面からはなくし、読み上げ用（支援技術向け）にだけ残す。
- 小さな地図: 全体の地図と同じ下地（建物・道路）と地下街の色・通路・経路を、進む向きが上になるよう回して描く。押すと全体の地図。
- 地図の色: 地面をクリーム色、建物を暖かいベージュ、大通りを薄い黄色、地下街を店街ごとのはっきりした色（ホワイティ=橙、ディアモール=緑、ドージマ=黄、ekimo=紫、三番街=桃）、通路を濃い水色に。

## テスト

- corridorPath（間引き・角での壁のつながり・区切り・切り詰め）、perspective（投影・手前の切り取り・交差）、corridorScene（曲がった先の通路・店ごとの店先・重なり回避・角に隠れる店・遠い店はアイコンだけ・目的地）、sceneInput（実データの経路で各区間）、MiniMap、FirstPersonView、App の流れ
- typecheck / format / lint / test（198件）/ build 通過。390×844 のスクリーンショットで確認
