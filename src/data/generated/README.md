# 生成データ（OpenStreetMap 由来）

`osmData.ts` は `scripts/osm/build.mjs` が OpenStreetMap の抽出データから生成する。手で編集しない。

- 元データ: © OpenStreetMap contributors
- ライセンス: [Open Database License (ODbL) 1.0](https://opendatacommons.org/licenses/odbl/1-0/)

このフォルダのデータは ODbL の派生データベースとして、同じ ODbL で提供する。
再生成の手順は [scripts/osm/README.md](../../../scripts/osm/README.md) を参照。
